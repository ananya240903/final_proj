# Paradise Nursery Shopping Application

Paradise Nursery is a React-based online plant shop where users can browse houseplants, add plants to a shopping cart, adjust quantities, remove items, and view dynamically updated cart totals.

## Features

- Paradise Nursery landing page with background image and Get Started button
- About Us section describing the company
- Product listing grouped into three plant categories
- At least six plants per category with image, name, and price
- Add to Cart buttons that disable after adding a plant
- Dynamic cart icon count
- Shopping cart with quantity increase/decrease controls
- Per-item totals and overall cart total
- Delete buttons for cart items
- Continue Shopping button
- Checkout button displaying a Coming Soon message
- Redux Toolkit cart state management

## Main Files

- `src/AboutUs.jsx`
- `src/App.css`
- `src/App.jsx`
- `src/CartSlice.jsx`
- `src/ProductList.jsx`
- `src/CartItem.jsx`

## Run Locally

```bash
npm install
npm start
```

Then open `http://localhost:3000` in your browser.
